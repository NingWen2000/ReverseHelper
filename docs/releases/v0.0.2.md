# ReverseHelper v0.0.2

v0.0.2 在保留默认完整分析行为的基础上，增加快速模式、单模块分析、清晰的输入错误和 CLI 专项测试。

## 主要更新

- `reversehelper sample.exe --quick`：快速完成 PE 结构、入口点、导入/导出和异常初筛；
- `reversehelper sample.exe --only anomaly`：只看加壳与结构异常；
- `reversehelper sample.exe --only strings`：只看字符串、编码和地址；
- `reversehelper sample.exe --only imports`：只看导入 API、IAT 地址和规则分类；
- 帮助页加入完整示例和含空格路径写法；
- 区分不存在、目录、不可读、非普通文件和非 PE 输入；
- 新增 CLI 调度、互斥参数、错误路径及真实 PE 集成测试。

## 安装

下载 `ReverseHelper-v0.0.2.zip` 或 Release 页的 `Source code (zip)`，解压后进入项目目录：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e .
reversehelper --version
```

版本命令应显示：

```text
ReverseHelper 0.0.2
```

## 使用

```powershell
reversehelper sample.exe
reversehelper sample.exe --quick
reversehelper sample.exe --only anomaly
reversehelper sample.exe --only strings
reversehelper sample.exe --only imports
reversehelper --help
```

`--quick` 与 `--only` 互斥。部分分析模式暂不生成完整报告；需要 Markdown、JSON 或 HTML 时使用默认完整分析。

完整变化、参数解释和 Python API 示例见仓库中的 `CHANGELOG.md`。
