# ReverseHelper v0.2.0b2 Beta — Simplified Chinese localization

本版本新增简体中文界面，保持同一分析引擎、Ranking 2.2、Schema 1.5 和 Benchmark 定义。默认仍为英文，不根据系统语言自动切换。主路线保持关闭，没有新增 detector 或分析规则。

## 使用

```powershell
.\ReverseHelper.exe .\challenge.exe --lang zh-CN
.\ReverseHelper.exe .\challenge.exe --lang zh-CN --deep
.\ReverseHelper.exe .\challenge.exe --lang zh-CN --ghidra
.\ReverseHelper.exe --lang zh-CN --help
```

- `--lang en / zh-CN` 控制 Quick/Deep 摘要、帮助、Markdown/HTML 报告和用户错误的展示语言。
- 普通 JSON 的字段、枚举、分析事实及原有说明保持不变。
- Ghidra 导出仅翻译 annotation 标题与注释，`RH:*` 分类、地址、置信度和证据保持稳定，不自动重命名。
- 新增中文版 README、QUICKSTART、workflow、limitations 和术语表。
- 支持中文路径；中文重定向输出使用 UTF-8，不改变系统区域设置或控制台代码页。
