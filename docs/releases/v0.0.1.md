# ReverseHelper v0.0.1

这是统一分析模式扩展之前的基线版本，保留用于下载、复现和与 v0.0.2 对比。

## 包含内容

- 完整 PE 静态分析流程；
- `reversehelper sample.exe` 基础命令；
- PE Header、Sections、Import/Export、Strings、Entropy、Overlay；
- EntryPoint、代码洞、密码学常量、加壳/异常和风险提示；
- Markdown、JSON、HTML 报告；
- Ghidra 辅助脚本与案例文档。

## 安装与使用

从 Release 页下载并解压 `Source code (zip)`，进入目录后运行：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e .
reversehelper sample.exe
```

v0.0.1 不支持 `--quick` 或 `--only`。需要这些模式时请下载 v0.0.2。

工具只读取目标 PE，不会执行它；启发式结果仍需在 Ghidra/x64dbg 中人工验证。
