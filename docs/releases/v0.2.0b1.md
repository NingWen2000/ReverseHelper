# ReverseHelper v0.2.0b1

`0.2.0b1` is the first Beta release of the integrated ReverseHelper competition workflow. Phase 1–4 are complete and closed. Phase 5 is not a prerequisite for using this release.

## Highlights

- one-command bounded Quick analysis by default;
- broader `--deep` analysis through the same analyzers and Schema 1.5;
- Challenge Summary with `START HERE` or `START WITH THESE`;
- input, static Slice, Validation, algorithm and control-flow evidence;
- Ranking 2.2 with evidence-backed review priorities;
- Markdown, HTML and JSON reports;
- unified `RH:*` annotations and bundled Ghidra importer;
- ASLR-safe x64dbg breakpoint suggestions;
- Windows x64 portable single-file executable.

ReverseHelper is a static triage and navigation aid. It does not execute the target, automatically solve challenges, unpack binaries, or replace Ghidra, IDA, DIE, PE-bear or x64dbg.

## Start

```powershell
.\ReverseHelper.exe --version
.\ReverseHelper.exe .\challenge.exe
.\ReverseHelper.exe .\challenge.exe --ghidra
.\ReverseHelper.exe .\challenge.exe --deep
```
